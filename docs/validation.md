## 真实链路证据

- 两条指定视频完成独立下载、星辰ASR V3.2、DeepSeek V4.1 Flash纠错、JSON摘要和发布，均成功且无纠错降级，未扫描订阅账号。原始证据在未提交的 `data/live_validation/`；精确运行时版本与权重指纹未记录。
- 三份摘要修正后重新生成并发布，对照输入未发现独立主题遗漏或跨主题错误合并；仍有转写专名疑点及摘要偏长问题，未对照音频或核验新闻事实。
- 公开日报页经桌面截图核对，证据为 `data/daily-preview.png`；本地导航入口及health集成检查通过，未发布线上导航变更。
- 一次Cookie登录检查返回HTTP 200 / code=-101 / isLogin=false，只证明该次凭据失效，更新凭据后需复验。

- 单条授权视频（331秒）的基线两次纠错输出完全一致，未见复核增益。最新实测使用用户确认、仅绑定该视频的五项术语，复用2294字原始ASR后调用一次DeepSeek V4.1 Flash（5.6秒）；Space Bunny、TRAE、Ming-3.0、Xing4.0-29B-Intent及GPT-Image-2.5 Sunburst均正确出现在最终稿，数字与术语检查通过，纠错清单完成且原稿不变，未发布。这证明已确认术语可修复该样本，不证明模型能够自行识别这些名称。证据在未提交的 `data/correction_validation/`。

## 未验边界

- 纠错仅完成一条真实样本的对照与人工术语修复验证，尚未验证未见视频的自动专名恢复准确率，也未评测完整音频或核验新闻事实；人工术语不等于自动检索能力。基线同模型复核没有增益，已移除额外模型复核，仅保留单轮纠错、术语校正和程序校验。数字守卫和术语出现次数检查不能发现全部语义错误。
- 安全加固仅经源码与离线验证，未进行公网渗透测试、依赖漏洞数据库审计或新成品包复验；实际HTTPS代理、防火墙、文件权限和云端Key权限需在服务器检查。
- Linux构建、无Python容器成品检查、systemd、海外服务器持续运行、4GB内存峰值、DNS和Tunnel尚未验收。已配置Linux构建工作流，但未在远端执行；部署操作见README。
- 本机缺少FFmpeg/FFprobe，成品仅验证了媒体依赖警告后网页可用；真实媒体分片和成品正常后台心跳待验。`scripts/smoke_bundle.py` 需在具备媒体工具的环境复验。
- Windows成品的setup-admin/setup-bili隐藏输入交互未实测，管理凭据使用临时夹具；对应业务门面已有单元测试。
- RSS真实抓取受本机代理Fake-IP DNS影响而被私网防护拒绝，未放宽防护；需在正常公网DNS环境补验。
- CookieJar和主动续期改动仅有离线验证，尚未验证真实刷新、改动后的下载、长期续期及浏览器共用登录影响。远端已处理请求但本地未收到响应的歧义未实测；文件锁只协调项目内访问。
- 后台管理业务、来源拖动与键盘排序、真实内容卡片布局未完成浏览器完整验收；清理仅在临时目录测试，未对用户数据执行，未测服务器磁盘峰值。

平台、下载器、模型接口或运行环境变化后需复验对应链路；离线结果不能替代受控真实验收。
